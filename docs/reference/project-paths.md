# 项目根与路径解析

这一页只回答一个问题：编译器从哪里找文件。答案由项目根和请求路径共同决定，和当前工作目录无关。

## 许可根与逻辑路径

项目根是一个已经规范化的绝对目录。许可集合就是它下面的普通 `.ts` 文件；符号链接只有在目标仍落在根内时才允许。入口和导入都写成项目内相对路径（斜杠分隔），文件身份也以这个相对路径为准。

项目根不是当前工作目录。`tynel build --root /work/shop src/main.ts` 从 `/tmp` 执行，入口仍然是 `/work/shop/src/main.ts`；换一个工作目录不会改变解析结果。

## 两个实际相对路径

假设项目根是 `/work/shop`，入口是 `src/main.ts`：

| 写法 | 从哪里找 | 结果 |
| --- | --- | --- |
| 入口 `src/main.ts` | 项目根 | `/work/shop/src/main.ts` |
| 从入口导入 `./lib/total.ts` | 入口所在目录 `src/` | `/work/shop/src/lib/total.ts` |
| 从入口导入 `../shared/value.ts` | 入口所在目录的上一级 | `/work/shop/shared/value.ts` |

第一条是入口解析，后两条是导入解析。`./` 和 `../` 都相对于**来源文件所在目录**，不是相对于工作目录，也不是相对于项目根。

## 解析流程

1. `Open(root)` 把根转成绝对路径，解析根自身的符号链接，要求它是目录。
2. 入口按项目根拼接；导入按来源文件目录拼接。拼接后先用 `path.Clean` 消掉 `.` 和 `..`。
3. 清理后的路径必须仍在根内，且以 `.ts` 结尾。导入不接受绝对路径、反斜杠或裸模块名；入口可以写成根内绝对路径，但会先转成相对路径再走同一条检查。
4. 逐段读取目录项，要求文件名大小写完全匹配。请求的大小写不对，或同一目录存在仅大小写不同的条目，都拒绝。
5. 最后一段可以是符号链接，但解析后的目标必须在根内；目标必须是普通文件。
6. 读一次字节，算出 sha256。`Path` 是相对路径，`Abs` 是绝对路径，`SHA256` 是内容身份。

失败后不补 `.ts`、不换目录、不搜索同名文件。解析器只认写出来的那一条路径。

## 拒绝条件

| 输入 | 错误码 | 退出 |
| --- | --- | --- |
| 入口或导入不存在 | `project.missing` | 1 |
| 导入是裸模块名，如 `工具.ts` | `project.bare-module` | 1 |
| 导入是绝对路径 | `project.absolute-path` | 1 |
| `../` 越出项目根 | `project.outside-root` | 1 |
| 符号链接目标在根外 | `project.outside-root` | 1 |
| 请求大小写与磁盘不一致 | `project.case-conflict` | 1 |
| 目标不是 `.ts` | `project.non-ts` | 1 |
| 目标不是普通文件 | `project.not-file` | 1 |
| 根不存在或不是目录 | `project.root-missing` / `project.root-not-dir` | 4 |

`project.missing` 和 `project.case-conflict` 都直接失败，不会尝试“找找看有没有别的拼写”。这条限制让构建结果可复现，也避免在大小写不敏感的文件系统上把两个不同名字混成一个。

## 文件身份

同一个根、同一条相对路径、同一份内容，得到同一个 `Identity()`：`相对路径@sha256`。绝对路径只用于启动前端宿主和显示诊断，不写进身份。`compiler/project` 的夹具包含中文、空格和两个不同目录下的同名文件，测试会确认它们不会被合并。

## 接口

| 接口 | 作用 |
| --- | --- |
| `Open(dir)` | 规范化项目根，只接受目录 |
| `ResolveEntry(name)` | 解析入口；支持根内相对路径或根内绝对路径 |
| `ResolveImport(from, request)` | 从来源文件目录解析 `./` 或 `../` 导入 |
| `File.Snapshot(limits)` | 用解析时读到的字节建立源码快照 |
| `File.Identity()` | 返回相对路径加内容哈希 |

## 本阶段不做

- 不读 `tsconfig.json`，不扩展 `paths` 或 `baseUrl`。
- 不解析裸模块、`node_modules` 或包导出。
- 不补后缀、不把目录当 `index.ts`。
- 不跟随根外符号链接，也不把工作目录当项目根。
