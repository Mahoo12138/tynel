## 正向验收

### 保存后读回一致

```text
=== RUN   TestRoundTripExample
--- PASS: TestRoundTripExample (0.00s)
```

测试读取 `examples/ir/add.nir.json`，编码成 JSON，再解码，用 `reflect.DeepEqual` 比较两次的结构；随后再编码一次，要求字节完全相同。字节相同意味着文件内容可以作为结构比较的依据，不受 map 顺序或空格影响。

### 负零、NaN 位模式与正负无穷

```text
=== RUN   TestSpecialValuesSurviveEncoding
--- PASS: TestSpecialValuesSurviveEncoding (0.00s)
=== RUN   TestNaNBitPatternKept
--- PASS: TestNaNBitPatternKept (0.00s)
```

覆盖六个值：负零、NaN、正无穷、负无穷、最小非零数和 42。每个值都检查两件事：`BitsOf` 与 `Float64` 往返后位模式不变；写入模块并编码后，文件里仍然出现原始位串，回读的 `bits` 与原值一致。

`TestNaNBitPatternKept` 单独固定载荷位：`0x7ff8000000000001` 经过 `BitsOf` 不得被改写成 `0x7ff8000000000000`。这条用例防的是「用 `math.NaN()` 重新构造」这种看似等价、实际丢载荷的写法。

### 示例结构

`TestExampleShape` 断言示例是 `main` 入口、两个函数，`add` 有两个 `number` 参数并返回 `number`，`main` 调用 `add` 且两个实参分别为 40 和 2。

### 不执行算术

本包没有求值代码：`binary` 节点只保存运算符和两个子节点，`+` 的含义由后端决定。测试也不计算 `40 + 2`，只检查结构。

## 负向验收

所有用例都断言：返回错误，且返回的模块为 `nil`（不输出半份模块）。

### 结构错误

| 输入 | 错误码 |
| --- | --- |
| `schemaVersion` 为 2 | `nir.version` |
| 缺少 `entry` | `nir.missing` |
| `functions` 为空 | `nir.missing` |
| `result` 为 `string` | `nir.bad-value` |
| 参数类型为 `string` | `nir.bad-value` |
| `print` 缺 `value` | `nir.missing` |
| 语句 `op` 为 `jump` | `nir.bad-op` |
| 表达式 `op` 为 `magic` | `nir.bad-op` |
| `number` 节点带 `name` | `nir.unexpected-field` |
| `bits` 为 `0x12` | `nir.bad-bits` |
| `number` 缺 `bits` | `nir.missing` |
| 运算符 `%` | `nir.bad-op` |
| `binary` 缺 `right` | `nir.missing` |
| `call` 缺 `function` | `nir.missing` |

### 解析层错误

| 输入 | 结果 |
| --- | --- |
| 截断到一半的 JSON | `nir.malformed` |
| 空输入 | `nir.malformed` |
| 合法文档后追加 `{}` | `nir.trailing` |
| 模块里多一个 `extra` 字段 | `nir.malformed`（`json: unknown field "extra"`） |
| `schemaVersion` 写成字符串 `"1"` | `nir.malformed` |

### 超限输入

| 超限项 | 构造 | 结果 |
| --- | --- | --- |
| 字节数 | `MaxBytes` 设为 16，输入大于 16 字节 | 拒绝，不进入解析 |
| 深度 | 71 层嵌套 `binary` | 拒绝，`MaxDepth` 为 64 |
| 节点数 | `MaxNodes` 设为 2 | 拒绝 |
| 函数数 | `MaxFunctions` 设为 2，实际 3 个 | 拒绝 |
| 预算配置非法 | 全零 `Limits` | 拒绝 |
